## 💻 Run Locally

Clone the repository:

```bash
git clone <your-repository-url>
```

Move into the project directory:

```bash
cd <repository-name>
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Then open the localhost URL displayed in your terminal.
